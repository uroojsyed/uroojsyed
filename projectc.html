OVERVIEW

Islamic Relief Canada is a national charity aimed at providing vital emergency aid around the world where disaster occurs and providing lasting routes out of poverty, transforming communities worldwide. Islamic Relief is one of eight organizations making up the Humanitarian Coalition.

ROLE: Digital Marketing Coordinator
TOOLS USED: Figma
SKILLS & CONCEPTS: User Research, Information Architecture, Brand Design, UX/UI Design, Donor Behaviour, & Audience Journey
DURATION: Aug 2021-Ongoing

OBJECTIVE

My team and I are currently collaborating on a complete website rehaul, which includes a thorough content update and transition to a cohesive CMS to allow greater functionality for donors and users. Alongside my superior, the Head of Technology, I spearheaded the research, planning, and design components of Islamic Relief Canada's website relaunch. My focus was on enhancing the user interface design in order to allow users and potential donors to have a more seamless experience with the added functionality in order to lead to greater conversions while also aligning the website look and feel more closely with the organization's brand image.

PROCESS

User Journey → Usability Heuristics Audit → User Flow → Mockups → Wireframing → Development

DEFINING THE GOALS: USER JOURNEYS

To better align the interaction design of the website, we must understand the end goals of different users and determine their needs in order plan their user journey and convert them into donors. Based on current evaluation of the website's users, we can identify three distinct goals.

  1. Informed donor that would like to simply donate to any of our causes in a quick and time-effective, hassle-free manner
  2. User who landed on the website through the user journey of our external marketing campaigns and would like to learn more about our missions. This is an opportunity to convert a user into a potential donor with enhanced CRM and UX design to allow effiency of use with clear and user-friendly.
  3. User that would like to get involved through volunteering or fundraising. This user would like to be a donor in a more immersive and hands-on way.
USABILITY HEURISTICS AUDIT

Potential hinderances that prevent successful user conversions from a lack of focus on the user experience can be determined by completing an audit of the website. I carried out a website audit against the Usability Heuristics for User Interface Design and key UX best practices by conducting research, and analyzing data and heatmaps.

  1. Visibility of System Status
    • Users should know how they arrived at certain pages (especially when these pages are only accessible by another page, and not the menu). Use breadcrumbs to show the user path.
  2. User Control and Freedom
    • Users aren’t able to edit their donation amount – instead, they have to remove the donation and start from scratch again. Adding a button that allows the users to edit their donation amount allows them more freedom without leaving the “Review Donation” step.
  3. Consistency and Standard
    • Clicking search will open a search bar that takes up the entire screen. Have the search bar open at the top of the page and keep the page visible.
    • Meeting accessibility standards by adding written content for screenreaders to accompany visual graphics. Open in a separate window so users can still access the IRC website and the blog at once without extra steps.
    • Create page consistency on information/donation pages. Some pages are busy and deviate from the standard design across the website.
  4. Aesthetic and Minimalist Design
    • The proportions for the homepage (navigation bar and bottom donate bar are too big, and distracting). The bottom donte bar can hide when a person scrolls.
  5. Help and Documentation
    • Chatbox with automated answers to help people navigate the website.Whenever possible, present the documentation in context right at the moment that the user requires it.

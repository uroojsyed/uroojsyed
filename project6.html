TELEMARKETING STRATEGY FOR BANKING - DATA ANALYSIS
CIND119 CULMINATING PROJECT

This data analysis and prediective modeling project uses the the Bank Marketing Dataset which explores the data of clients pertaining to a telemarketing campaign conducted by Portuguese banking institution. The problem we aim to uncover through this data analytics study is how to use the data presented in this dataset to make an informed decision for an effective telemarketing strategy. We will analyze this dataset and conduct a predictive model set using Python for most of the data visualization manipulation, and machine learning for some further explorative analysis. We solve this problem by breaking down the individual attributes of all the clients and studying their respective correlation to the class variable of the dataset which is ‘Y’, yes for if the clients successfully subscribed to a term deposit or no for if they did not subscribe. We organized the attributes in terms of their relevance to the class variable to determine which influence the class attribute or which are correlated to each other by generating various plots for a visualization. Next, we clean up the data in order to prepare predictive models for the classification by using the algorithms of decision trees and naïve bayes to allow us to predict the class attribute most accurately. After doing this, we assess the accuracy of our predictive models through performance measures by identifying which algorithm performs well out of the 2. We conducted 2 of each algorithm, one with the full dataset and one with a manipulated dataset. We discovered that the accuracy of the Naïve Bayes model with the manipulated dataset, in which we omitted non-significant attributes, has the highest accuracy at 90%. Finally, we concluded that this banking institution will have an effective telemarketing with a higher rate of term deposit subscriptions in class variable ‘Y’ if they focus on the attributes we selected for the limited dataset for the Naïve Bayes model.

ROLE: Data Scientist
TOOLS USED: Python & Tableau
